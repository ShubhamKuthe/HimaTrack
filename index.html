How to Use HimaTrack

Start Tracking

Sign in once and HimaTrack starts detecting the active application automatically. Keep it open or minimized to the tray while you work.

Background Mode

Minimize or close the window to send HimaTrack to the Windows tray. Tracking keeps running until you choose Quit HimaTrack from the tray menu.

Idle Time

If there is no keyboard or mouse activity for 60 seconds, tracking pauses and shows Idle. It resumes automatically when you return.

Tasks

Use New Task to label future tracked time. Clear the task name when you want tracking to go back to app/window names only.

Views

Overview shows live totals, Review shows history, Details shows app paths, and Reports summarizes top apps and projects.

Filters

Use the range selector for Past 30 Days, Past 7 Days, or Day. Search filters the visible app/window history in the current range.

Cloud Sync

Your account is handled by Firebase. Choose Windows or Mac in the toolbar to view tracked time from that platform.

macOS Permissions

On Mac, allow HimaTrack in Accessibility and Screen Recording so it can detect the active application and window title.

Mac Permission Check

Open these settings if tracking cannot see the active app or window title on macOS.

Reset

Reset clears the signed-in user's tracked time and restarts the current clock from zero. Use it only when you want a clean history.
